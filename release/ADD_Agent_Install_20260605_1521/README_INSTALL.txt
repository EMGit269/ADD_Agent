Maipo 安装说明

1. 将 ADDGH 文件夹复制到 Grasshopper Libraries 目录，或在 Grasshopper 中手动加载 ADDGH\ADDGH.gha。
2. 保持 skills 和 reference 文件夹与安装包内结构一致，用于插件运行时读取内置技能和示例参考文件。
3. 启动 Rhino / Grasshopper 后，菜单中显示名称为 Maipo。

主要文件：
- ADDGH\ADDGH.gha
- ADDGH\CanvasWeb\dist
- skills\
- reference\

如果 Windows 阻止加载 .gha，请右键 ADDGH\ADDGH.gha，打开属性，勾选“解除锁定”，然后重新启动 Rhino / Grasshopper。
