# Reference Index

使用流程（与建模三阶段对应）：
1. **阶段一**：先主动浏览下列参考条目，了解当前有哪些可参考的 reference 及其概括内容。
2. **阶段二**：再结合用户需求与这些概括内容，形成文字级 GH 方案（数据流、关键电池类型、是否需非破坏性实验方案等）；可据此做适度补强、校验或细化，但不要让参考替代自主思考。
3. **阶段三**：仅当某条目与**已定/拟定方案**高度相关时，再调用 `read_reference_json` 传入 `file_name`，用 JSON 做定向学习，在画布上对齐细节、补充或改造实现。
